What changed from the single-processor version

Each module is its own file under processors/, loaded as a real ES module over HTTPS — no Blob/data-URL workaround needed now that this is served from GitHub Pages instead of a sandboxed preview.

The graph is wired with plain node.connect(destination, outputIndex, inputIndex) calls. The mixer node declares numberOfInputs: 2, so delay.connect(mixer, 0, 1) reads exactly like a patch cord landing in a specific inlet.

Swap, reorder, or add modules by editing the wiring in connectGraph() below — the processors themselves don't need to know what's upstream or downstream of them.
